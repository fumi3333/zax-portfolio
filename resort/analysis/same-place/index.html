同じ住所の求人を突き合わせると、会社の違いだけで時給が最大350円ちがった

集計日 2026-09-30／掲載中の求人6,802件のうち、住所が一致した37か所

分かったこと
  • 同じ住所に2社以上が求人を出していたのは37か所。 うち29か所で時給に差があり、8か所は同額でした
  • 差の中央値は50円、最大は350円 （北海道勇払郡占冠村：株式会社ダイブ1,700円 と スタッフエージェント1,350円）
  • 常に同じ会社が高いわけではありません。どの会社も、高いほうにも安いほうにも立ちます

なぜこの比べ方に意味があるのか

別ページの重回帰の分析では、県・職種・寮・期間をそろえると 会社による差は時給63円ぶんまで縮みました。つまり「どの会社か」より「どこで何をするか」のほうが ずっと大きく効きます。

ただしあれは全国をならした話で、県より細かい条件まではそろえられていません。 ここでは同じ住所に出ている求人だけを比べています。施設も仕事も寮も立地も丸ごと同じなので、 残る違いは通す会社だけです。統計で調整するより強く条件がそろいます。

その状態でも29か所で差が残り、中央値で50円ありました。 平均すると小さい会社差が、個別の現場では無視できない大きさで出ることがある、ということです。

この数字の限界

  • 住所で同定できるのは全体の一部です。多くの求人は番地まで公開していないため、 実際にはもっと多くの重複があるはずですが、確認できたぶんだけを載せています
  • 時給が同じでも、寮費・食事・交通費の扱いで手取りは変わります。 ここで比べているのは時給の額面だけです
  • 募集時期がずれている場合、差が会社ではなく時期によるものである可能性があります
